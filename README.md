# Informations
This project is a simulation of a landmine detection system using ground-penetrating radar (GPR). The simulation is done using Python and the output is saved as a csv file.
You can then use the csv file to visualize the output and perform a DBSCAN clustering to detect the landmines.
# How to run the code
1. Clone the repository to your local machine
```bash
git clone https://github.com/mathiasbalian/gpr.git
```
2. Open the terminal and navigate to the project folder
3. Run the following command to install the required packages
```bash
pip install -r requirements.txt
```
4. Run the following command to start the application
```bash
python gpr.py
```

```bash
python dbscan.py
```
